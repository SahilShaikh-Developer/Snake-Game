# Snake Game

A simple browser-based Snake game built with vanilla HTML, CSS, and JavaScript.  
This project recreates the classic Snake gameplay with score tracking, a timer, and persistent high scores using localStorage.

---

## 🎮 Features

- Grid-based snake movement  
- Keyboard arrow key controls  
- Wall collision detection  
- Self-collision detection  
- Food spawning that avoids the snake body  
- Score system (+10 points per food)  
- High score saved in browser localStorage  
- Game timer (MM:SS format)  
- Start game modal screen  
- Game over modal screen  
- Restart game functionality  

---

## 🕹️ Controls

| Key         | Action        |
|-------------|---------------|
| Arrow Up    | Move Up       |
| Arrow Down  | Move Down     |
| Arrow Left  | Move Left     |
| Arrow Right | Move Right    |
